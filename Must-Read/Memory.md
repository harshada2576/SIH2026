# Memory.md — Running Progress Log (starts empty, grows as you build)

Each pair should keep a running log here (or a copy of this file in their own workstream folder) so if you switch AI chat sessions or tools mid-build, you can paste in the recent log instead of re-explaining everything from scratch.

Suggested format per entry — adapt however works for your pair:

```
### [Date] [Workstream name]
- What we built/changed today:
- Current state (what works, what doesn't):
- Blockers / waiting on:
- Next step:
```

*(No entries yet — first person to sit down and build tonight/tomorrow starts this. Keep entries short — a few lines, not a full changelog. The point is just enough context that a fresh AI chat session isn't starting blind.)*

# Design.md — Visual Direction (loose, low priority, edit as you like)

This is intentionally minimal — functionality and the scalability demo matter far more than visual polish for this prototype. Whoever ends up on the dashboard can fill this in as they build, or ignore it entirely if time is short.

## Suggested starting point (change anything)
- Map-first layout: large map view (Leaflet) as the centerpiece, with a side panel for alert details/evidence.
- Risk color scale: something intuitive, e.g. green → yellow → red for low → high risk terminals.
- Keep it readable from the back of a presentation room — bigger fonts, high contrast, minimal clutter.

## Not decided yet / up to whoever builds it
- Color palette specifics
- Font choices
- Whether to add any branding/team name treatment
